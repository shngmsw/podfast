# Skill: retake-detect (podcast-edit)

Claude Codeが言い直しを検出する際の判断基準。

## 言い直しとは
話者が同じ内容を言い直している箇所。後の発言（より完成度が高い方）を採用する。

## 検出パターン

### パターン1: 即座の言い直し
「これは、あ、これはとても重要な...」
→ 最初の「これは、あ、」をカット

### パターン2: 文の途中で中断して再開
「昨日のミーティングでは、えーと、昨日のミーティングで決まったのは...」
→ 「昨日のミーティングでは、えーと、」をカット

### パターン3: 言い間違いの訂正
「3月、あ、4月に開催します」
→ 「3月、あ、」をカット

## 判断しないケース（カットしない）
- 意図的な繰り返し（強調）: 「本当に、本当に大事なんです」
- 相槌や合いの手: 「うんうん」「そうそう」
- 別の話者の発言が間に入っている場合
- 言い直しではなく補足・追記の場合

## 出力形式
retake_result.json:
```json
{
  "retakes": [
    {
      "start": 12.5,
      "end": 14.2,
      "type": "immediate_retake",
      "original_text": "これは、あ、",
      "kept_text": "これはとても重要な話で",
      "speaker": "SPEAKER_00"
    }
  ]
}
```

## 注意
- 迷ったらカットしない（保守的に判断）
- ポッドキャストは多少の言い淀みが自然。完璧を求めすぎない
- 話者が変わっている場合は言い直しではない
