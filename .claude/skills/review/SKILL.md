# Skill: review (podcast-edit)

Claude Codeが文字起こし結果の品質チェックを行う際の判断基準。

## チェック項目

### 1. WhisperX認識ミスの修正
- 同音異義語の誤認識: 「以上」↔「異常」、「機会」↔「機械」
- カタカナ語の表記ゆれ: 文脈から正しい表記を推定
- 固有名詞: 話の文脈から正しい表記を推定（確信度が低い場合は元のまま）

### 2. 固有名詞の表記統一
- 同一エピソード内で表記を統一
- 正式名称が推定できる場合は正式名称に統一
- 不明な場合はカタカナ表記のまま残す

### 3. 数字の正規化
- 漢数字 → 算用数字: 「三百万」→「300万」
- 年号: 「令和六年」→「令和6年」/ 「二千二十四年」→「2024年」
- ただし慣用表現はそのまま: 「一石二鳥」「四苦八苦」

### 4. 句読点
- WhisperXが過剰に付与する句読点を整理
- 読点が多すぎる場合は自然な位置のみ残す
- 句点は文末に適切に付与

## 修正しないケース
- 方言・口語表現: 話し言葉として自然なものはそのまま
- 話者の癖: 特徴的な言い回しは個性として残す
- 不確実な修正: 確信度が低い場合は元のテキストを維持

## 出力形式
review.json:
```json
{
  "corrections": [
    {
      "original": "きかい学習",
      "corrected": "機械学習",
      "reason": "文脈から機械学習が正しい",
      "word_index": 42
    }
  ],
  "proper_nouns": ["WhisperX", "Claude Code", "Silero VAD"],
  "quality_score": 0.92,
  "notes": "全体的に認識精度は高い。固有名詞の修正が3箇所。"
}
```
